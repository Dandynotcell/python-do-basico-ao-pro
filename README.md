# Python do Básico ao Pró

Curso interativo em HTML, CSS e JavaScript para guiar iniciantes em uma jornada de programação com Python: fundamentos, ferramentas profissionais, POO, APIs, banco de dados, dados, automação, testes, deploy, segurança e portfólio.

## Objetivo

Transformar um roadmap de estudos em uma experiência prática, com aulas clicáveis, progresso salvo no navegador, exercícios, quizzes, projetos e fontes confiáveis.

## Funcionalidades

- 8 módulos de estudo.
- 37 aulas interativas.
- Progresso salvo com `localStorage`.
- Busca por aulas.
- Mini quizzes por tópico.
- Exercícios guiados.
- Plano de 24 semanas.
- Projetos de portfólio.
- Biblioteca de fontes, documentações e livros.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como abrir

Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html`, `README.md` e `.gitignore`.
3. No GitHub, acesse `Settings > Pages`.
4. Em `Build and deployment`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve e aguarde o link público ser gerado.
